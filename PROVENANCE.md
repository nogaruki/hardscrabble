# Provenance

Hardscrabble is a clean-room reimplementation inspired by MITE (*Minecraft Is Too Easy*) by Avernite.
It is not affiliated with Avernite and holds no agreement with them (ENF-LEG-03).

## Code

- Written from the project specifications only: `../docs/01..03` and the feature matrix `../analysis/06`, whose rows cite
  their source (public R196 changelog, wiki pages, MC百科, project design). The only MITE file the team may read is the public
  `change_log.txt` (ENF-LEG-01, ENF-LEG-04).
- No MITE class, jar or decompiled source is in this repository (ENF-LEG-05). CI checks it with
  `tools/check-cleanroom.sh` and the identifier denylist `tools/cleanroom-denylist.txt` (ET-Q-07).
- Minecraft and NeoForge APIs were looked up in decompiled 26.3 sources kept outside the repository (`../ref-src`).

## Assets

| Asset | Origin |
|---|---|
| `assets/hardscrabble/textures/**` | Original pixel art drawn by script with `tools/pixelart/` (rules in `docs/art/STYLE.md`, owners in `docs/art/INVENTORY.csv`). Colours come only from `tools/pixelart/palettes.py`; no vanilla or MITE texture is copied, traced or sampled |
| Mob UV templates `docs/art/uv/` | Generated from model box sizes (geometry), not from vanilla images |
| `data/hardscrabble/structure/platform.nbt` | GameTest platform built for this project (stone floor) |
| `src/generated/resources/**` | Generated by `./gradlew runData` from the Java sources |
| Mob models, sounds | None of our own yet: MITE mobs reuse vanilla models and sounds by reference at runtime (nothing copied) |
